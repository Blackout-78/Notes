Notes 0.2.0: Windows and Linux versions.

Added:
- Notes now runs on Windows and Linux with the same screens, notes and backups as the phone app.
- Wider layout with a multi-column note grid on big screens, plus Ctrl+N (new note), Ctrl+F (search) and Esc (back).
- Windows blocks screenshots and screen recording of the window when Screen protection is on (not available on Linux).

Fixed:
- Nothing changed for Android besides the shared layout update.
