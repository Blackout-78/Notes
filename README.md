# Notes

A private, fully offline note app for Android.

- Rich text: headings, bold, italic, underline, text color, highlight
- Lists: bullets, checklists, numbers, Roman numerals, letters, nested outlines
- Paragraph tools, links (web, phone, email, other notes), tables, pictures
- Folders, tags, search, pin, trash, backup file
- Military date and time (24-hour)
- No internet permission, no Google services, no analytics

Install: download the APK from the newest release on the Releases page.
